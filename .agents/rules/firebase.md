# Firebase Rules

These rules govern database updates, storage policies, security rules, and deployment procedures for Firebase services.

## Firebase Workflow
* Follow `docs/codex/FIREBASE_EXECUTION_CONTEXT.md` before running any Firebase CLI commands.
* If Firestore schema changes, update `FIRESTORE_COLLECTIONS.md`.
* If rules or index deployment steps change, update `FIRESTORE_DEPLOYMENT_GUIDE.md`.
* If upload paths, accepted file types, or file requirements change, update `FILE_UPLOAD_IMPLEMENTATION.md`.
* **Do not deploy Firestore rules, Storage rules, or indexes without explicit approval.**
